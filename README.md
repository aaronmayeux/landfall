# SHIPS corpus

A season of NHC SHIPS diagnostic files, fetched from
<https://ftp.nhc.noaa.gov/atcf/stext/>.

**Read `inventory.json` first.** It describes what is in
`files/` — the non-numeric tokens that appear where numbers
belong, the section headings, the row labels and which of
them are not in every file, forecast lengths, and how late a
run can be published. Opening individual files without it is
how a session burns its context.

Data, not code. Never merged into `main`.
